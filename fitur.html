Fitur SiPaud

Fitur untuk guru PAUD

SiPaud difokuskan untuk guru sekolah PAUD sebagai pengguna. Hanya ada dua peran: Admin (kepala sekolah) dan Guru. Tidak ada angka statistik atau data pengguna contoh di halaman ini.

👥

Dashboard Admin & Guru

Admin memantau rekap bulanan; Guru mengisi laporan harian.

✅

Absensi Guru

Guru absen dengan foto selfie dan lokasi GPS, hanya bisa dalam radius 20 meter dari sekolah.

🧒

Absensi Murid

Guru menandai murid Hadir, Izin, Sakit, atau Alpa per kelas, tanpa foto dan lokasi.

📄

Rekap PDF Bulanan

Hasil absensi direkap dalam bentuk PDF setiap bulan.

📈

Grafik Absensi

Grafik elegan kehadiran guru dan murid per bulan.

Grafik Per Bulan

Grafik terisi otomatis dari data bulanan. Sebelum ada data nyata, grafik dibiarkan kosong.

Data Absensi

Persentase kehadiran guru dan murid per bulan.

Progres Anak

Persentase progres perkembangan anak per bulan.
